# Aurum | أوروم — Luxury Salla Theme

ثيم فاخر داكن بلمسات ذهبية لمنصة سلة، مبني على ثيم رائد الرسمي (MIT) مع طبقة تصميم كاملة جديدة.

**مناسب لـ:** العطور، المجوهرات، الأزياء الراقية، الساعات، الهدايا الفاخرة.

## المميزات
- تصميم داكن فاخر مع تدرجات ذهبية وخطوط عربية أنيقة (El Messiri) وإنجليزية (Cormorant Garamond).
- أقسام رئيسية خاصة: **واجهة أوروم الفاخرة**، **قصة العلامة**، **شريط متحرك ذهبي** + كل أقسام رائد.
- حركات ناعمة لبطاقات المنتجات والواجهة، مع احترام إعداد تقليل الحركة.
- دعم كامل للعربية والإنجليزية وجميع صفحات سلة (السلة، المنتج، الحساب، المدونة...).

## التطوير
```bash
pnpm install
pnpm production   # يبني الملفات إلى public/
salla theme preview
```
